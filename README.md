# QR Code Decoder

This web application allows you to decode QR codes from images or directly from your camera. All processing is done locally in your web browser, ensuring your data remains private and is never shared with third parties.

## Features

- Drag and drop an image (PNG or JPG) to decode the QR code.
- Click to select a file from your device.
- Paste an image from the clipboard (Ctrl+V / Cmd+V).
- Scan QR codes directly using your camera.
- Copy the decoded text to the clipboard with a single click.

## Usage

1. Open the web application in your browser.
2. Drag and drop an image, click to select a file, or paste an image.
3. Alternatively, click the "Scan from Camera" button to use your camera.
4. The decoded QR code text will be displayed on the screen.
5. Click the "Copy decoded text to clipboard" button to copy the text.

## Technologies Used

- HTML
- CSS
- JavaScript
- [jsQR](https://github.com/cozmo/jsQR) library for QR code decoding
